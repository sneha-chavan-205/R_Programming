# R Programming – Practical 02

## 📌 Overview

This repository contains the work completed for **R Programming Practical 02**.

The practical focuses on working with datasets in R, including data loading, cleaning, preprocessing, and analysis.

## 📂 Files Included

- `R_Programming_Practical02.ipynb` – Jupyter Notebook containing the practical implementation.
- `cleaned_heart_data.csv` – Cleaned Heart Disease dataset.
- `cleaned_adult_data.csv` – Cleaned Adult dataset.
- `.gitkeep` – Keeps the Practical02 directory tracked by Git.

## 🛠️ Technologies Used

- R Programming
- Jupyter Notebook
- CSV Datasets
- Data Cleaning & Preprocessing

## 🎯 Objective

To understand and implement basic data preprocessing and analysis techniques using R on real-world datasets.

## 📊 Datasets

The practical uses the following datasets:

1. **Heart Disease Dataset**
2. **Adult Dataset**

The datasets have been cleaned and stored separately as CSV files for further analysis.

## ▶️ How to Run

1. Clone this repository.
2. Open `R_Programming_Practical02.ipynb` using Jupyter Notebook.
3. Make sure the required datasets are present in the `Practical02` folder.
4. Run the notebook cells sequentially.
